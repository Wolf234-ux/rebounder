# Change Mee Rebounder

Interactive 3D scroll website for Change Mee Rebounder — professional 44-inch bungee rebounder.

## Features
- **Interactive 3D Frame Scroller**: Smooth frame-by-frame 3D animation synced to scroll.
- **Single-File Architecture**: Self-contained static site with Three.js rendering.
- **Hash Routing**: Instant navigation across `Home`, `Product`, `Benefits`, `Story`, `Gallery`, and `Contact`.
- **Responsive & Polished**: Optimized spacing, responsive typography, and anti-overlap layout across mobile, tablet, and desktop.

## Deploying to Render
1. In Render Dashboard: **New +** > **Static Site**.
2. Connect this repository (`rebounder`).
3. Set:
   - **Build Command**: *(leave empty)*
   - **Publish Directory**: `.`
4. Click **Create Static Site**.
